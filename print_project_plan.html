2. Rural Problem Statement vs The GramSetu Solution

❌ Critical Rural Bottlenecks
  • Zero / Unstable Internet: Farmlands & remote villages lack reliable 4G/5G; cloud AI apps (ChatGPT) crash immediately.
  • Illiteracy & Language Barriers: Text-heavy English portals alienate millions of vernacular Hindi/regional speakers.
  • Exploitation & Delayed Help: Farmers suffer crop loss due to lack of timely advisory; citizens miss DBT scheme deadlines.
✅ The GramSetu Offline Solution
  • 100% On-Device AI Bundle: Quantized Qwen 2.5 (1.5B/0.5B GGUF) runs locally via llama.cpp without needing 1 byte of internet.
  • Voice-First Bilingual Interaction: Offline Sherpa-ONNX Speech-to-Text & Native Android TTS in natural Indian Hindi accents.
  • Curated Offline RAG Engine: Embedded SQLite FTS5 database delivers grounded, verified facts for schemes & farming.

4. Complete Technical Stack Breakdown

Layer Technology / Framework Offline Rationale & Key Architectural Advantage
Mobile Frontend Flutter 3.x (Dart) Cross-platform 60fps UI, native C++ FFI interop with llama.cpp, lightweight memory footprint, smooth audio visualizers.
Core LLM Qwen 2.5 (1.5B / 0.5B) GGUF Q4_K_M Top-tier bilingual Hindi reasoning; quantized to <1.1GB RAM; generates 14-18 tokens/sec on standard budget Android phones.
Inference Engine llama.cpp (C++ / Android NDK) Optimized ARM NEON matrix multiplication, 4-thread CPU parallelism, zero server cost, zero data leakage.
Speech-to-Text Sherpa-ONNX / Whisper-tiny 40MB local acoustic model; highly accurate on Indian Hindi phonetics; transcribes 5s speech in <1.1 seconds.
Text-to-Speech Android Native TTS (hi-IN) Zero additional binary weight; native Indian Hindi accent; immediate audio playback for illiterate villagers.
Knowledge RAG SQLite with FTS5 / SQLite-Vec Sub-15ms keyword & semantic search; zero memory overhead; preloaded with 50+ govt schemes & 200+ crop advisories.
Dev Tooling Google Antigravity IDE AI-assisted sprint orchestration, automated test prompts, C++ bridge generation, and instant code refactoring.

10. Risk Management & 3-Minute Live Pitch Strategy

⚠️ Identified Risks & Fallback Strategy
  • Low RAM Crash (OOM): Dynamic memory monitor automatically falls back to Qwen-0.5B if free RAM is under 1.4GB.
  • Noisy Background: Integrated software noise-gate + one-tap visual category buttons for silent interaction.
  • Scheme Hallucinations: Strict RAG prompt forces model to state "यह जानकारी डेटाबेस में उपलब्ध नहीं है" if score is low.
🏆 3-Minute Live Demo Pitch Script
  1. 0:00 - 0:30 (The Hook): Turn on Airplane Mode on stage. Show 0 WiFi and 0 Cellular bars.
  2. 0:30 - 1:30 (Live Voice Test): Tap mic & speak in Hindi: "मेरी गेहूं की फसल में पीला रतुआ लग गया है, क्या करूँ?" Model answers in voice + text in 2s.
  3. 1:30 - 2:15 (Yojana Checklist): Ask: "PM किसान योजना के 6000 रुपये के लिए कौन से कागजात चाहिए?" Shows checklist.
  4. 2:15 - 3:00 (Vision & Scale): Highlight privacy, zero server cost, and scalability to 600,000+ Indian villages.
