------------------------------------------------------------------------
💻 WINDOWS PC पर कैसे चलाएं / Install करें:
------------------------------------------------------------------------

तरीका 1: Direct 1-Click Launch (सबसे आसान)
  1. "Run_GramSetu_Windows.bat" पर double-click करें।
  2. GramSetu server चालू हो जाएगा और आपका Browser (Chrome/Edge) खुद ब खुद खुल जाएगा।
  
तरीका 2: Standalone .EXE File बनाना:
  1. "GramSetu_Setup_Windows.bat" पर double-click करें।
  2. यह अपने आप PyInstaller सेटअप करके "GramSetuAI.exe" फाइल बना देगा।
  3. अब आप केवल "GramSetuAI.exe" पर double-click करके किसी भी PC पर चला सकते हैं!

तरीका 3: Background / Silent Mode:
  1. "GramSetu_Silent.vbs" पर double-click करें। (बिना black screen के चलेगा)

------------------------------------------------------------------------
🍎 MAC (macOS) पर कैसे चलाएं:
------------------------------------------------------------------------
  1. "Start_GramSetu_Mac.command" पर double click करें।
  2. GramSetu AI Browser में अपने आप खुल जाएगा।
