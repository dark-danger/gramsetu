Slide 1

1. Project Kya Hai? (What is GramSetu AI?)

Core Pitch: GramSetu AI ek voice-first, fully offline generative AI application hai jo rural Bharat aur village populations ke liye banaya gaya hai. Yeh bina kisi internet connection ke kheti (agriculture), sarkari yojana (govt welfare), primary health/first-aid aur daily problem solving me instantly guide karta hai.

Main Pillars:

  • 100% Offline & Local: Device ke andar chalne wala local AI engine (Qwen 2.5 3B via Ollama/llama.cpp).
  • Multilingual Voice Support: Natural Hinglish, Shuddh Hindi (Devanagari) aur Punjabi (Gurmukhi) me baatcheet.
  • Zero Hallucination Guarantee: Deterministic SQLite User Memory aur curated ground truth RAG engine se verified answers.
  • Specialized Agent Tools: Acre-to-Bigha land conversion aur DAP/Urea/Seed dosage calculator.

3. Galat AI Jawab (Hallucinations) Cloud LLMs kheti aur dawaiyo me ulte-seedhe numbers bol dete hain. Deterministic Memory & RAG — 100% verified sarkari aur scientific data.
4. Calculation Ki Kathinai Zameen ka hisab (Acre, Bigha) aur khad ki matra nikalna mushkil hota hai. Automated AgriMath Tools — 1 click me exact bags aur kg hisab.

4. Core Technical Modules & Features

🌾 Kisan Mitra (Agricultural Advisory)

  • Gehu Ki Buwai: 40-45 kg/acre seed rate, 1 bag DAP, 2 bags Urea.
  • Pehla Pani (CRI Stage): Buwai ke 20-25 din baad zaroori sinchai.
  • Peela Ratua: Propiconazole 25% EC @ 200ml/acre spray.

🏛️ Sarkari Yojana (Govt Welfare Schemes)

  • KCC Loan: 4% effective interest rate, ₹1.6 lakh collateral free.
  • PM Fasal Bima (PMFBY): 1.5% Rabi, 2% Kharif premium, 72-hr claim.
  • PM-KUSUM: Solar agricultural pump par 60% tak subsidy.

🩺 Swasthya & First-Aid Salah

  • Bukhar (Fever): Paracetamol 500/650mg, cold sponging, ORS liquid.
  • Snake Bite Protocol: Immobilize limb, DO NOT tie tourniquet, rush for Anti-Snake Venom (ASV).

⚡ Upgraded AI Model: Qwen 2.5 (3B)

  • 1.5B model se upgrade karke 3B parameters model lagaya gaya hai.
  • Strict To-The-Point Reasoning prompts: No rambling, no looping, crisp 2-4 points direct answer.
